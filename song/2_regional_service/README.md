# 🗺️ Layer 2: Regional Problem-Solving Service (지역 문제 해결 서비스)

`1_data_infrastructure`가 제공하는 데이터 인프라(정규화 DB, MCP Server)를 기반으로, **경상북도 폭염 대응 TF와 현장 인력이 직접 사용하는 대시보드 웹 애플리케이션 및 의사결정 지원 서비스**입니다.

---

## 📂 디렉토리 구조

```
2_regional_service/
├── app.py                    # [대시보드 백엔드] Flask 기반 REST API 및 정적 서빙 서버
├── briefing.py               # [AI 브리핑] 파이프라인 산출 사실 → Claude API로 판정형 서술 생성
└── static/
    └── index.html            # [대시보드 프론트엔드] Leaflet 기반 인터랙티브 지도 & 실시간 분석 UI
```

---

## 🤖 AI 브리핑 (`briefing.py`)

대시보드 상단에 **"오늘 어느 마을부터 확인해야 하는지"** 를 3~4문장으로 요약합니다.

**숫자는 코드가, 서술만 AI가 담당합니다.**

```
파이프라인 계산  →  "위험단계 375/392, 쉼터·순찰 모두 없는 곳 13개소,
                     1순위 구미시 해평면(86.7)"
        ↓ 이 확정된 사실만 모델에 전달 (DB 접근 권한 없음)
Claude API      →  판정형 문장으로 서술
```

모델이 숫자를 지어내면 "판단 근거를 검증할 수 있어야 한다"는 이 프로젝트의 전제가
무너지므로, 사실 수집(`collect_facts`)과 서술(`generate`)을 분리했습니다.

| 항목 | 동작 |
|---|---|
| 캐시 | 사실 다이제스트 기준. 데이터가 그대로면 API를 다시 부르지 않습니다 |
| 키 없을 때 | 규칙 기반 문장으로 자동 대체 (숫자는 동일, 문장만 투박해짐) |
| 호출 실패 시 | 동일하게 규칙 기반으로 degrade — **대시보드는 멈추지 않습니다** |
| 출처 표시 | 화면에 `AI 생성` / `규칙 기반` 뱃지로 구분 표기 |

```bash
# 사용하려면 (선택)
cp .env.example .env   # ANTHROPIC_API_KEY 입력
```

## 🌟 주요 해결 과제 및 기능

1. **경북 392개 읍·면·동 + 24개 시군구 위험도 시각화 지도**:
   - 실시간 체감온도와 정적 취약도(고령인구·초고령 쏠림·쉼터 결핍·온열질환 이력)를 결합한 위험도 등급(양호/주의/경고/위험) 색상 표출
2. **도보 5분(400m) 쉼터 사각지대 판정**:
   - 경북 전역 5,605개 무더위쉼터 위치 및 반경 400m 도보권 분석 (미도달 시 사각지대 경고)
3. **카카오맵 길찾기 및 쉼터 시설 상세 연동**:
   - 에어컨/선풍기 보유 수, 야간/주말 개방 여부, 수용인원 정보 제공 및 길찾기 연동
4. **AI 상황 브리핑**:
   - 흩어진 지표를 "오늘 어디부터 가라"는 판정으로 요약 (아래 참조)
